# First-audiobook workflow maps

These SVGs are explanatory workflow maps, **not screenshots** and not generated application output. Labels were checked against `app/static/index.html` and `app/static/js/app-core.js` at app commit `8006baa05294139de4d64eb16683b6c77624cb9a`.

- `first-audiobook-en.svg`: English steps and checkpoints.
- `first-audiobook-zh-CN.svg`: the same path with Chinese explanations and the original English UI labels.

No LLM, TTS model, GPU render, or finished audio was tested for this documentation update. Checkpoints describe what the reader must verify on their own run. The original narration sample is in `../samples/first-audiobook.txt`.

Actual UI capture was attempted but not obtained: the cloud browser could not reach the temporary preview server, and the available headless renderer could not start in the execution sandbox. No simulated screenshots were substituted.
