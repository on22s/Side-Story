# User-provided recorded sound effects

These 28 files were imported from the user's local `~/Downloads/sfx` directory on
2026-08-19. The source directory was read-only during import and remains unchanged.

Project copies were converted with FFmpeg to mono 48 kHz, 16-bit PCM WAV. Peak level
was adjusted toward -3 dBFS before the per-cue gain in `manifest.json` is applied.
Long ambience was trimmed to 30 seconds; forest/grass footsteps were trimmed to 12
seconds; one-shot effects retain their full duration.

The files are user-provided, not procedurally generated by Alexandria. Their presence
in this workspace does not establish a redistribution license. Review the original
license before publishing or redistributing them. Embedded metadata was found in
`water/water_ambience_loop.wav`: title `Tempo: 120.0`, artist `Collin Scudder`, and
copyright `2018 Epic Stock Media (Quest Game) https://epicstockmedia.com`.
